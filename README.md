# Compander 0.1

Creative frequency-sensitive analog-delay and dbx-inspired compander, built with JUCE 8 as a Windows VST3.

The DMM-style mode is a perceptual frequency-selective model, not a measured Deluxe Memory Man circuit. The dbx-style mode approximates broadband 2:1 encode / 1:2 decode. **dbx Type A is not an established dbx format**; Dolby A is a different multiband noise-reduction system.

Controls: Amount (0–200%), HF Emphasis, Split Frequency, Input, Output, Compressor On, Expander On, Bandwidth and mode selector.
